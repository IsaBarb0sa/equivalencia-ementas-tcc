# Sistema de Equivalência de Ementas

## Objetivo

Automatizar a análise de similaridade entre ementas acadêmicas,
auxiliando processos de transferência e dispensa de disciplinas.

## Tecnologias

- Python 3.11+
- SQL Server 2022
- SQLAlchemy
- pyodbc
- pytest
- PyCharm
- Clean Architecture
- Domain-Driven Design

## Estado atual

- Banco de dados criado.
- Conexão Python–SQL Server configurada.
- Estrutura da Clean Architecture criada.
- Cadastro de instituição implementado.
- Cadastro de curso implementado.
- Cadastro de disciplina implementado.
- Testes unitários das entidades implementados.
- Modelagem de matriz curricular iniciada.

## Próximas etapas

- Finalizar matriz curricular e vínculo com disciplinas.
- Cadastrar versões de ementas.
- Cadastrar conteúdos programáticos.
- Implementar upload e extração de PDFs.
- Construir baseline com TF-IDF.
- Implementar embeddings e similaridade semântica.
- Validar resultados com pareceres humanos.
